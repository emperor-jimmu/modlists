# Expanded Systems

## Character Creation And Starting Choices

### Core Idea

This subsection is about how `Elder Wilds` begins a playthrough: how much freedom the player gets at the start, how strongly the opening is tied to roleplay identity, and whether the list wants a clean alternate start, a more immersive in-world intro, or a highly freeform sandbox opening.

The goal is to support replayability and roleplay expression without immediately colliding with later race, progression, religion, survival, or follower-system decisions.

### Suggested Options

- Structured immersive route: use `Alternate Perspective - Alternate Start` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/50307> if the list wants a more grounded in-world opening and a cleaner transition into the game world.
- Classic baseline route: use `Alternate Start - Live Another Life` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/272> if the list wants the most familiar and historically proven alternate-start baseline.
- Modular detached route: use `Skyrim Unbound Reborn (Alternate Start)` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/27962> if the list wants a more configurable start framework without committing fully to the more abstract sandbox style.
- Freeform sandbox route: use `Realm of Lorkhan - Freeform Alternate Start` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/18223> if the list wants a more open character-setup space with heavier roleplay freedom right from the beginning.

### Pros And Cons

- `Alternate Perspective - Alternate Start` pros: stronger world-connected opening, better fit for an immersive list identity, and a more deliberate handoff into ordinary play.
- `Alternate Perspective - Alternate Start` cons: more opinionated opening structure, easier to justify only if that extra immersion is actually felt in play, and less conservative than the classic baseline.
- `Alternate Start - Live Another Life` pros: familiar, proven, easy to understand, and a very clean fallback if the project wants a restrained alternate-start solution.
- `Alternate Start - Live Another Life` cons: more utilitarian feel, weaker world-presence than the immersive route, and less distinctive if `Elder Wilds` wants the opening itself to carry tone.
- `Skyrim Unbound Reborn (Alternate Start)` pros: highly configurable, strong for testing different early-game setups, and more flexible than the classic baseline without going fully sandbox-first.
- `Skyrim Unbound Reborn (Alternate Start)` cons: more detached/system-like feel than the immersive route, easier to drift into setup-tool territory, and less naturally grounded than a world-integrated opening.
- `Realm of Lorkhan - Freeform Alternate Start` pros: strongest immediate roleplay freedom, fast build experimentation, and the clearest option if the list wants a sandbox-like opening philosophy.
- `Realm of Lorkhan - Freeform Alternate Start` cons: easiest to feel abstract or gamey, weaker fit for a grounded opening tone, and more likely to pre-tilt the whole list toward freeform setup over world cohesion.

### Recommendation

Start with the grounded modern route. Treat `Alternate Perspective - Alternate Start` as the main baseline candidate because it fits the project's immersive tone while still keeping the opening disciplined and readable. Keep `Alternate Start - Live Another Life` as the conservative fallback comparison if the newer route proves harder to justify in the final stack. Treat `Skyrim Unbound Reborn (Alternate Start)` as the more configurable middle-ground alternative if the list wants extra setup freedom without going all the way to a sandbox-first opening. Treat `Realm of Lorkhan - Freeform Alternate Start` as the more radical roleplay-forward option, not the default baseline.

### Why This Is The Right Baseline

`Elder Wilds` is already leaning toward a strongly embodied third-person experience with modern presentation and expanded systems. That makes a simple “skip Helgen and pick a start” solution useful, but not sufficient by itself. `Alternate Perspective` is the best first candidate because it keeps the opening connected to the world rather than turning start selection into a detached utility menu. `Live Another Life` remains important as the reliable comparison point because it is straightforward, widely understood, and easier to justify if the project later chooses restraint over novelty. `Skyrim Unbound Reborn` matters because it covers the configurable alternate-start space without fully committing to the more abstract sandbox tone. `Realm of Lorkhan` is still worth keeping in view because it represents a different philosophy entirely, but it should only win if the list deliberately wants that level of freeform setup.

### Working Guidance For Elder Wilds

- Keep this subsection focused on start flow and opening roleplay, not race, perk, religion, or survival mechanics.
- Test the opening for tone, onboarding clarity, and how naturally it hands the player into the early game.
- Prefer a start framework that helps replayability without making the first fifteen minutes feel like a detached configuration room.
- Preserve room for later progression decisions to matter; the starting mod should not quietly pre-answer the whole build identity.
- Use the fallback comparison on purpose instead of leaving multiple alternate-start paths half-adopted.

### What Elder Wilds Should Prioritize

- A start that supports replayability without feeling gimmicky.
- Strong roleplay support that still preserves world coherence.
- Clean handoff from character start into the normal game loop.
- Minimal overlap with later progression, religion, or survival decisions.
- A baseline that is easy to explain and easy to test.

### Research Tasks

- Confirm `Alternate Perspective - Alternate Start`, `Alternate Start - Live Another Life`, `Skyrim Unbound Reborn (Alternate Start)`, and `Realm of Lorkhan - Freeform Alternate Start` all behave cleanly on Steam `1.6.1170`.
- Test whether `Alternate Perspective` actually improves immersion enough to justify choosing it over the simpler classic baseline.
- Check whether `Skyrim Unbound Reborn` offers genuinely useful flexibility or just adds more start-configuration overhead.
- Check whether the project wants a grounded start flow or a more overt freeform roleplay opening.
- Record any early-game conflicts with later city, quest, survival, or follower decisions as those sections are expanded.
- Decide whether the eventual opening should preserve more vanilla framing or intentionally move farther away from it.

### Risks To Check

- Start mods can quietly carry world-state assumptions that ripple into later quest or location decisions.
- A highly freeform opening can weaken early-game tone if it feels too abstract or gamey.
- A more immersive start can still lose value if it adds setup friction without improving the actual first-play experience.
- This subsection can become muddy if race, perk, survival, or religion decisions start leaking into it too early.

### Acceptance Criteria

- `Elder Wilds` has one clearly preferred starting framework and one meaningful fallback comparison, not a pile of overlapping start mods.
- The chosen route improves replayability and roleplay identity without undermining world coherence.
- The opening feels compatible with the project's immersive tone and later expanded-systems work.

## Race, Standing Stone, And Progression Overhauls

### Core Idea

This subsection decides how strongly `Elder Wilds` should reshape the player's long-term identity through race traits, standing stones, and early-to-midgame character progression. The key question is not just power level, but tone: should these systems stay readable and restrained, or become a major part of build expression and character definition.

The goal is to choose one clear progression philosophy before moving into perk, magic, alchemy, and religion decisions that will depend on it.

### Suggested Options

- Balanced modern route: use `Aetherius - A Race Overhaul` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/26686> with `Evenstar - Minimalistic Standing Stones of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/41256> if the list wants meaningful character identity while staying disciplined and readable.
- Minimalist restraint route: use `Morningstar - Minimalistic Races of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/22298> with `Evenstar - Minimalistic Standing Stones of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/41256> if the list wants lighter-touch race and stone changes that support the rest of the build without dominating it.
- High-expression route: use `Imperious - Races of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/1315> with `Andromeda - Unique Standing Stones of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/14910> if the list wants race and standing stones to become much more central to build identity.

### Recommendation

Start with the balanced modern route. Treat `Aetherius - A Race Overhaul` plus `Evenstar - Minimalistic Standing Stones of Skyrim` as the main baseline because that pairing gives `Elder Wilds` stronger character identity than vanilla without making race and standing stones feel like the entire progression game. Keep `Morningstar - Minimalistic Races of Skyrim` plus `Evenstar` as the restrained fallback if the final list wants less systemic pressure. Treat `Imperious - Races of Skyrim` plus `Andromeda - Unique Standing Stones of Skyrim` as the more dramatic comparison route, not the default baseline.

### Why This Is The Right Baseline

`Elder Wilds` already has big ambitions in presentation, movement, and general gameplay feel. That makes it risky to front-load too much mechanical identity into race and standing stones before the rest of the progression stack is settled. `Aetherius` with `Evenstar` is the strongest first baseline because it gives visible character-definition value without immediately pulling the project toward a highly gamified build-planning experience. `Morningstar` matters because it preserves a much more restrained, almost vanilla-plus direction if the final list needs space for other systems to carry the weight. `Imperious` with `Andromeda` remains valuable as the intentional high-expression route, but it should only win if the project deliberately wants players making much stronger build commitments from race and stone choice alone.

### Working Guidance For Elder Wilds

- Keep this subsection focused on race traits, standing stones, and broad progression tone, not perk trees or spell-system details.
- Compare whole philosophies, not isolated mod names; race and stone picks should be judged as a pair.
- Prefer one progression baseline that is easy to explain to a new player.
- Watch for whether these systems create interesting identity or just add hidden optimization pressure.
- Leave room for later perk, magic, religion, and economy sections to matter.

### What Elder Wilds Should Prioritize

- Clear build identity without excessive rules overhead.
- A progression tone that matches the list's immersive, third-person-first direction.
- Strong readability for ordinary players, not just experienced theorycrafters.
- Enough distinction between characters to support replayability.
- Minimal unnecessary overlap with the later perk and magic decisions.

### Research Tasks

- Confirm `Aetherius - A Race Overhaul`, `Morningstar - Minimalistic Races of Skyrim`, `Imperious - Races of Skyrim`, `Evenstar - Minimalistic Standing Stones of Skyrim`, and `Andromeda - Unique Standing Stones of Skyrim` all behave cleanly on Steam `1.6.1170`.
- Test whether `Aetherius` plus `Evenstar` gives enough character identity without crowding later systems.
- Check whether `Morningstar` is too light for the intended list identity or exactly the restraint the final build needs.
- Check whether `Imperious` plus `Andromeda` feels meaningfully richer or just more mechanically dominant.
- Record any pressure these choices place on the later perk-overhaul subsection.

### Risks To Check

- Race and stone overhauls can quietly pre-decide too much of the character-building experience before perk and magic systems are chosen.
- A highly expressive route can push the list toward optimization-heavy play even if the broader project wants a more immersive tone.
- A minimal route can undershoot if the rest of the expanded-systems stack ends up expecting stronger identity hooks.
- Mixing progression philosophies later can produce a stack that is individually interesting but incoherent as a whole.

### Acceptance Criteria

- `Elder Wilds` has one clearly preferred race-and-stone philosophy, one restrained fallback, and one more dramatic comparison route.
- The chosen baseline supports replayability and character identity without dominating the rest of the progression stack.
- Later perk, magic, and religion decisions still have room to matter.
- `mods-checklist.md` lists only the verified race-and-stone candidates this subsection is actively comparing.

## Perk Overhaul Compatibility

### Core Idea

This subsection chooses the perk-tree philosophy that the rest of `Expanded Systems` will need to live with. The goal is not just to pick the most famous perk mod, but to decide how much rules density, specialization pressure, and build expression `Elder Wilds` actually wants once race and standing-stone choices are already in place.

### Suggested Options

- Balanced modern route: use `Adamant - A Perk Overhaul` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/30191> if the list wants a cleaner progression baseline with meaningful choices but restrained complexity.
- Restrained fallback: use `Vokrii - Minimalistic Perks of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/26176> if the goal is to stay closer to vanilla readability while still improving perk variety.
- High-expression route: use `Ordinator - Perks of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/1137> if the list intentionally wants more dramatic build definition and a denser long-term perk game.

### Recommendation

Start with the balanced modern route. `Adamant - A Perk Overhaul` is the strongest first-pass baseline because it meaningfully improves character building without immediately forcing the entire list into an optimization-heavy identity. Keep `Vokrii - Minimalistic Perks of Skyrim` as the more conservative comparison if `Adamant` still feels more system-forward than the final tone wants. Keep `Ordinator - Perks of Skyrim` as the deliberate high-complexity route only if `Elder Wilds` decides it wants perks to be one of the dominant sources of build identity rather than one layer among several.

### Why This Is The Right Baseline

`Elder Wilds` already wants expanded systems, but it also wants readability, immersive tone, and room for later decisions in magic, economy, religion, and survival-adjacent play. `Adamant` fits that middle ground best: it is easier to reason about than a full high-density perk framework, but still more decisive than a near-vanilla fallback. That makes it a strong anchor while the rest of `modlist-05.md` is still unresolved.

### Working Guidance For Elder Wilds

- Keep this subsection focused on perk philosophy and compatibility pressure, not spell-package design or race-system ownership.
- Judge perk overhauls by how they affect ordinary leveling, role identity, and long-term build clarity, not just by how many interesting perk nodes they add on paper.
- Compare each candidate against the already-preferred race-and-stone direction so the total progression stack feels coherent.
- Prefer one primary perk route early enough that later magic, crafting, and religion decisions can be made against it instead of against three parallel possibilities.
- Watch for whether the chosen perk framework rewards immersive play patterns or quietly pushes the list toward constant build optimization.

### What Elder Wilds Should Prioritize

- Clear build identity without turning every level-up into heavy rules parsing.
- Good compatibility headroom for later magic, alchemy, crafting, and religion choices.
- A progression style that remains understandable to a player returning after time away from the list.
- Enough perk differentiation to support replayability without demanding encyclopedic system knowledge.
- A perk baseline that complements the existing immersive and third-person-first project tone.

- Test whether `Adamant` leaves enough room for later magic and crafting expansion without feeling too sparse.
- Check whether `Vokrii` is the right amount of restraint or whether it undershoots the "expanded systems" pillar.
- Check whether `Ordinator` creates compelling long-term build identity or simply overwhelms the rest of the progression stack.

## Magic System Expansion

### Core Idea

This subsection chooses the spell-system philosophy for `Elder Wilds`: how broad, readable, and build-defining magic should feel once the race, standing-stone, and perk baseline are in place. The goal is to pick one clear magic direction that complements the chosen progression stack instead of overwhelming it.

### Suggested Options

- Balanced modern route: use `Mysticism - A Magic Overhaul` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/27839> if the list wants a cleaner, more complete spell baseline that stays readable and works naturally with the current progression direction.
- Moderate expansion route: use `Odin - Skyrim Magic Overhaul` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/46000> if the list wants a broader and slightly flashier spell package without fully turning magic into the dominant system pillar.
- High-expression route: use `Apocalypse - Magic of Skyrim` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/1090> if the list intentionally wants a much denser spell sandbox with stronger build experimentation and spell variety.

### Can They Be Used Together

- `Mysticism` and `Odin` should be treated as competing primary magic overhauls, not as a default stack. They occupy too much of the same design space to be the clean baseline together.
- `Apocalypse` is the most plausible add-on candidate if the list wants to start from a primary overhaul and then layer in more spell variety later.
- The safest planning baseline for `Elder Wilds` is still to choose one main overhaul first, validate the perk-and-magic philosophy, and only then decide whether an additional spell pack is actually needed.
- If the list later explores combined setups, that should be treated as a deliberate compatibility project rather than the assumed default direction for this section.

### Pros And Cons

- `Mysticism - A Magic Overhaul`
- Pros: clean fit with a restrained-to-balanced progression stack; easier to reason about as a baseline; less likely to drown later systems in spell volume.
- Cons: may feel too restrained if the final list wants magic to be one of its showpiece systems; can undershoot players who want large numbers of novel spells.
- `Odin - Skyrim Magic Overhaul`
- Pros: broader and more expressive than the restrained baseline; stronger chance of making magic feel visibly expanded without going straight to maximum spell sprawl.
- Cons: sits in an awkward middle if the list ultimately wants either very disciplined restraint or full magical excess; still competes with other primary overhauls rather than neatly stacking with them.
- `Apocalypse - Magic of Skyrim`
- Pros: strongest spell variety and experimentation of the three; easiest way to push magical build identity into a more dramatic space; most plausible candidate to revisit as an additive layer.
- Cons: highest risk of overwhelming the rest of the progression stack; easiest route to spell-list bloat; more likely to push the project away from a calm readable baseline.

### Recommendation

Start with the balanced modern route. `Mysticism - A Magic Overhaul` is the strongest first-pass baseline because it expands and cleans up the magic game without immediately pulling the entire project toward spell-volume spectacle or heavy build-complexity. Keep `Odin - Skyrim Magic Overhaul` as the comparison route if `Mysticism` ends up feeling too restrained for the final identity. Keep `Apocalypse - Magic of Skyrim` as the deliberate high-expression option, and the most plausible later additive layer, only if `Elder Wilds` decides it wants spell variety and magical build experimentation to be a dominant part of the whole list rather than one well-integrated subsystem.

### Why This Is The Right Baseline

The current direction in `modlist-05.md` already leans toward a balanced, readable progression stack: `Aetherius` plus `Evenstar` and `Adamant` as the leading baseline. `Mysticism` fits that philosophy cleanly. It gives magic users more complete tools and a more deliberate framework without forcing every later decision in alchemy, religion, crafting, or economy to orbit an extremely high-volume spell ecosystem.

### Working Guidance For Elder Wilds

- Keep this subsection focused on spell-system direction, not enchantment balance, religion identity, potion design, or staff-specific side systems.
- Judge each candidate by how it affects ordinary play for mages, spellswords, and hybrid builds, not just by the raw count of new spells.
- Compare magic candidates against the currently preferred perk and progression baseline so the full character-building stack stays coherent.
- Prefer one primary magic route before later alchemy, religion, and economy work begins to avoid building the rest of the file around multiple incompatible assumptions.
- Treat `Mysticism` versus `Odin` as a primary-overhaul decision first; do not assume both belong in the baseline together.
- Treat `Apocalypse` as a later volume-and-variety question rather than proof that the main overhaul choice was incomplete.
- Watch for whether a candidate creates meaningful magical identity or simply adds more buttons than the list actually needs.

### What Elder Wilds Should Prioritize

- Clear magical identity for common archetypes without excessive spell-list sprawl.
- Strong compatibility headroom for later alchemy, religion, economy, and crafting decisions.
- A readable spell ecosystem that ordinary players can understand without memorizing a giant catalog.
- Enough magical variety to make spell-focused characters feel expanded, not just patched.
- A spell baseline that matches the immersive and progression-focused tone already forming in `Expanded Systems`.

### Research Tasks

- Confirm `Mysticism - A Magic Overhaul`, `Odin - Skyrim Magic Overhaul`, and `Apocalypse - Magic of Skyrim` all behave cleanly on Steam `1.6.1170` with the current framework stack.
- Confirm whether any combined setup under serious consideration actually has a clean compatibility path, rather than assuming spell overhauls are naturally stackable.
- Test whether `Mysticism` gives enough breadth for dedicated magic builds without making the system feel too conservative.

- Check whether `Apocalypse` creates compelling magical build diversity or simply overwhelms the rest of the progression stack with volume.

- A restrained spell overhaul can undershoot the `Expanded Systems` pillar if too many other subsections also land on conservative choices.

## Survival Systems

### Core Idea

This subsection should decide how much day-to-day bodily upkeep `Elder Wilds` actually wants: enough hunger, fatigue, cold, weather, disease, and wilderness friction to support roleplay and travel texture, or a heavier survival framework that becomes one of the list's central systems. The goal is to choose a survival baseline here, while leaving `modlist-11.md` to handle later survival-compatibility, difficulty-pressure, and balance interactions across the full load order.

### Suggested Options

- Simonrim-aligned route: use `Starfrost - A Survival Overhaul` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/97536> if the list wants a modern survival baseline that fits the current `Aetherius`/`Adamant`/`Mysticism`/`Apothecary` direction.
- Restrained modern route: use `SunHelm Survival and needs` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/39414> if the list wants a readable mainstream survival baseline without turning the game into a constant maintenance simulator.
- Heavier classic route: use `Last Seed - Survival Needs and Diseases` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/56393> if the list intentionally wants a more involved needs framework with stronger disease-and-upkeep identity.
- Harsh wilderness route: use `Frostfall - Hypothermia Camping Survival` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/671> together with `Campfire - Complete Camping System (Supports Skyrim VR)` - Nexus: <https://www.nexusmods.com/skyrimspecialedition/mods/667> if the list wants cold-weather travel and camping to become a major pillar rather than a light background system.

### Pros And Cons

- `Starfrost - A Survival Overhaul`
- Pros: strongest philosophical fit with the repo's current Simonrim-like progression stack; easier to justify as a coherent system choice rather than a side add-on; likely to preserve a readable modern tone.
- Cons: narrower ecosystem and less "default Skyrim survival" familiarity than the older big names; may feel too deliberately tuned if the final list wants a more general-purpose or harsher survival identity.
- `SunHelm Survival and needs`
- Pros: readable and widely adopted modern baseline; easier to test as a restrained survival layer; strong chance of adding travel texture without dominating every build.
- Cons: can feel a little generic next to the more tightly themed progression stack already forming; may undershoot if the final list wants survival to carry more of the roleplay weight.
