# Mythic Crucible — Baldur's Gate 3 Modlist

A curated 2-wave modlist and game guide for Baldur's Gate 3 (Patch 8 / Hotfix #36 — April 2025).

## What's Inside

| Wave | For | Mods | Focus |
|------|-----|------|-------|
| **0 — First Steps into Faerun** | Beginners | 12 verified mods | UI/QoL + bug fixes + lightweight graphics |
| **1 — Mythic Crucible** | Experienced | 17 verified mods (+ unverified candidates) | New content, mechanics, combat overhaul |

## Quick Start

1. **Install BG3MM** — `guide/01-installation.md`
2. **Wave 0 (beginners):** Read `guide/02-wave-0-guide.md`, install mods from `guide/03-wave-0-modlist.md`
3. **Wave 1 (experienced):** After completing Wave 0, start fresh with `guide/04-wave-1-guide.md` and `guide/05-wave-1-modlist.md`
4. **Load order:** `guide/06-load-order.md`

## Full Documentation

All guides are in the `guide/` directory. A compiled PDF is available at `output/mythic-crucible.pdf`.

## Mod Verification

All Wave 0 mods and core Wave 1 mods have individually verified Nexus Mods URLs. Additional Wave 1 candidate mods are listed in `mod-ideas.md` for future verification.

## Build

To regenerate the PDF:

```bash
build.bat
```

Requires [Typst 0.15.x](https://github.com/typst/typst) and [Node.js](https://nodejs.org).
