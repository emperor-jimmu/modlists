# Wave 0 — Visuals & Reshade

## Reshade

No FS25-specific Reshade presets were found on Nexus Mods, FS25.net, or ModHub as of July 2026. Instead:

1. Install Reshade using the [Reshade guide](../reshade.md)
2. Use the default effects package
3. Enable these effects for a natural look:
   - **Levels** — adjust brightness and contrast
   - **Vibrance** — subtle color enhancement
   - **SMAA** — anti-aliasing (better performance than in-game MSAA)
   - **LumaSharpen** — subtle sharpening without over-processing
   - Optional: **AmbientLight** for warmer sunrises/sunsets

Oak Bridge Farm already includes custom lighting, so keep Reshade effects conservative.

## Not Available

The following FS22 visual mods have not been ported to FS25:

- **Relight** — FS22 lighting overhaul, no FS25 version exists
- **Skybox/weather mods** — no dedicated FS25 visual mods found on any platform
- **Reshade presets** — no community presets published for FS25 yet (Nexus Mods FS25 section has 132 mods, none are reshade presets)

Use manual Reshade tuning and rely on Oak Bridge Farm's built-in lighting instead.
