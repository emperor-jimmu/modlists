# Truck Mods

Truck mods add new drivable vehicles — from real-world brands not officially licensed in ETS2 (Mack, Peterbilt, Ford) to high-detail reworks of existing SCS trucks (Scania NG, MAN TGX, Volvo FH). This section covers standalone trucks, reworks, and interior/dashboard accessories confirmed or likely compatible with ETS2 **1.60**.

### Notes

- **Standalone vs replacement:** All truck mods listed are standalone — they add a new truck alongside SCS defaults rather than replacing them. You can own both.
- **Mod dealer purchases:** Many truck mods use a separate "Mod Dealer" location for purchases rather than the standard brand dealer.
- **ProMods compatibility:** Map mods like ProMods can conflict with truck dealer locations (e.g., Ford F-Max's Berlin dealer). Check compatibility before combining.
- **Load order:** Truck mods generally go anywhere in the mod manager — they do not depend on specific load order positions unless stated otherwise. Place above map mods if using a combined profile.
- **Sound banks:** Some truck mods (Mercedes 1632 NG, Ford F-Max) include separate sound bank downloads or optional sound files. Read the mod description carefully.
- **Physics mods:** Only one physics mod should be active at a time. Stacking physics mods causes unpredictable handling.
- **Scania NG parts:** The Venus, Rear Bumper, and SRI Lightbox mods are tuning-only additions for the SCS Scania NG. They can be combined freely.
