# Stellar Dominion

An X4 Foundations v9.0 modlist and game guide organized in progressive waves.

## Prerequisites
- X4 Foundations v9.0 (Steam/GOG)
- Mod Organizer 2 (latest)
- Node.js (for PDF preprocessing)
- Typst 0.15 (for PDF compilation)

## Quick Start
1. Install Mod Organizer 2 and configure for X4 (see `guide/mo2-installation-guide.typ`)
2. Choose your wave — see `guide/wave-setup.typ` for the recommended start
3. Install the mods listed for your wave (from `guide/mod-data/wave-N.yaml`)
4. Follow the strategy guide for your wave

## Building the PDF
```
.\generate-pdf.bat "Your Name"
```

## Waves
| Wave | Name | Difficulty | Theme |
|---|---|---|---|
| 0 | The Uncharted | Normal | Learn the game |
| 1 | The Opportunist | Moderate | Expand your influence |
| 2 | The Warlord | Hard | Conquer the galaxy |
| 3 | Stellar Dominion | Very Hard | Master the universe |
