# Portraits & Models

Character appearance, clothing, unit models, and equipment.

## Community Flavor Pack

- **Link:** https://steamcommunity.com/sharedfiles/filedetails/?id=2220098919
- **Mod Version:** 1.19.x
- **CK3 Version:** 1.19.x
- **Updated:** 2026-06-20
- **Load Order:** Early (before EPE)
- **Essential:** Yes
- **Performance:** Moderate (~2-5 FPS on GPU)
- **Dependencies:** None
- **Incompatibilities:** Other major clothing asset overhauls (use compatibility patches)
- **System/Mechanic Impact:** Visual — cultural clothing sets, headgear, building models, unit models
- **Installation Notes:** Install before EPE. If using both CFP and EPE, also install the CFP+EPE Compatibility Patch.
- **Configuration:** None

Adds thousands of new cultural clothing sets, headgear, building models, and unit models. Every culture group gets unique visual identity. Largest content mod for CK3.

**Gameplay Impact:** Purely visual. The world looks dramatically more diverse. Western Europeans look different from Eastern Europeans, Indians, Africans, etc.
