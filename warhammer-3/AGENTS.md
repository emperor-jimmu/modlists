# When Gods Bleed — Agent Instructions

This is a Total War: Warhammer III modlist and game guide project for version 8.1.1 (July 16, 2026).

## Project Structure

- `guide/` — Wave-based guide and modlist source files (by category)
- `output/` — Generated PDF output (not committed)
- `assets/` — Logo and other assets (`logo.png`)
- `conflicts.conf` — Conflicting mods list (excluded from PDF)
- `mod-ideas.md` — Future mod ideas (excluded from PDF)
- `template.typ` — Typst PDF template
- `build.bat` — Batch script to regenerate the PDF
- `RPFM.md` — RPFM mod manager setup guide

## Key Rules

- Mods must be compatible with TWWH3 v8.1.1 (or released within ~1 year of this version)
- No conflicting mods in the same wave
- No pornography mods; adult/nude is acceptable where relevant to the game
- No redundant mods that add the same content
- No cheating/overpower/all-knowing mods
- Mod entries include: clickable name with URL, dependencies, system/mechanic impact
- PDF is generated by running `build.bat` (uses Typst 0.15)
- Conflicts and mod ideas are NOT part of the PDF output

## PDF Generation

```
build.bat
```

This runs Typst to compile `template.typ` into `output/when-gods-bleed.pdf`.

## Mod Entry Format

Each mod entry in a modlist should specify:
- Name (linked to mod URL)
- Version/tag
- Dependencies (other mods required)
- System or mechanic impact description
- Any known conflicts
