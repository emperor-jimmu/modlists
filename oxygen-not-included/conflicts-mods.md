# Known Mod Conflicts

> Not included in the PDF. This file tracks mods that conflict with each other or with the target build.

- (no conflicts among the 27 accepted mods themselves — verified pairwise on the Workshop pages, 2026-08-21)
- **Ronivan's Legacy - Industrial Revolution** supersedes the 12 individual industrial mods it consolidates (Chemical Processing, Mineral Processing - Metallurgy, etc.). Do NOT install those standalone mods alongside it — they are the sector content now folded into the pack.
- **Pliers** and **Build Over Plants** are superseded by the base game (features merged in); do not run the obsolete Workshop versions.
