# Map & Environment

Visual and terrain improvements for the game map.

## Clear Map

- **Link:** https://steamcommunity.com/sharedfiles/filedetails/?id=2847198345
- **Mod Version:** 1.19.x
- **CK3 Version:** 1.19.x
- **Updated:** 2026-06-12
- **Load Order:** Early
- **Essential:** Yes
- **Performance:** None
- **Dependencies:** None
- **Incompatibilities:** None known
- **System/Mechanic Impact:** Map rendering — fog of war overlay removal
- **Installation Notes:** None
- **Configuration:** None

Removes the fog of war overlay on the map, making all terrain, holdings, and borders clearly visible even in areas you don't control.

**Gameplay Impact:** Purely visual — makes map exploration and planning easier. Does not reveal hidden information (FOW remains on characters and armies).

- **System/Mechanic Impact:** Map rendering — place name localisation, cultural naming

## Medieval Arts

- **Mod Version:** 1.19.x
- **CK3 Version:** 1.19.x
- **Updated:** 2026-06-15
- **Load Order:** Mid
- **Essential:** No
- **Performance:** Moderate
- **Dependencies:** None
- **Incompatibilities:** Other monument/building asset mods (use A Special World compatch)
- **System/Mechanic Impact:** Map rendering — 3D monuments, buildings, map objects

**Gameplay Impact:** Purely visual. The map becomes dramatically more detailed and immersive. Each major city and historical site has a unique appearance.

## A Special World — Special Building Compatch

- **Link:** https://steamcommunity.com/sharedfiles/filedetails/?id=2875587269
- **Mod Version:** 1.19.x
- **CK3 Version:** 1.19.x
- **Updated:** 2026-06-10
- **Load Order:** Late (after Medieval Arts, MB+, RICE)
- **Essential:** No
- **Performance:** Minor
- **Dependencies:** Medieval Arts, More Bookmarks+, RICE (or other supported mods)
- **Incompatibilities:** None (designed to resolve conflicts)
- **System/Mechanic Impact:** Map rendering — special building conflict resolution
- **Installation Notes:** Load after all map-building mods. Only needed if running multiple building/monument mods.
- **Configuration:** None

Compatch that ensures special buildings from Medieval Arts, Cities of Wonder 3, Unique Buildings+, RICE, More Bookmarks+, Africa Plus, and Muslim Enhancements display correctly together without overlapping or missing models.

**Gameplay Impact:** Fixes visual conflicts between map-enhancing mods. Required if running multiple building/monument mods together.
