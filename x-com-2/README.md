# The 3rd Coming - XCOM 2 Modlist & Guide

A game guide and modlist scaffold for **XCOM 2: War of the Chosen** (last official patch Build 8270065, 24 February 2022), organized by mod category. "The 3rd Coming" is the project's name for this build: the resistance that fell, rose, and comes again.

- Modlist: **[WOTC] Core Collection** (75 mods) - user-supplied baseline on 2026-08-12, transcribed into the per-category modlist files (`guide/modlists/`); rules in `AGENTS.md` + `STATUS.md`
- Mod source: Steam Workshop (by far the largest community for this game)
- Mod organizer: Alternative Mod Launcher (AML) - <https://github.com/X2CommunityCore/xcom2-launcher/releases> (community standard)
- PDF: run `build.bat` to regenerate `output/the-3rd-coming.pdf`

## Structure
- `guide/` - Typst sources (installation, overview, how-to-play, vanilla-strategy, per-category modlist files)
- `output/` - generated PDF (`the-3rd-coming.pdf`)
- `STATUS.md` - live decision log (decisions, open questions, user instructions)
- `conflicts-mods.md` / `mod-ideas.md` - not included in the PDF
