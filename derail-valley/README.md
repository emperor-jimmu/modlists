# Iron Valley — README

Curated modlist and game guide for **Derail Valley** (Steam app 588030, current live build **B99.7** — the final B99 stability patch of 2025-08-02, plus the October 2025 Unity security patch; B100 is in development and not released), built on the community-standard **Unity Mod Manager (UMM)**. The guide covers installing the manager and mods, the curated modlist itself (with the deliberate omissions), a how-to-play field manual for the modded career, and five player personas.

## What's inside

| File | Content |
|---|---|
| `guide/10-installation.typ` | Steam B99.7 → Unity Mod Manager (the mod manager) → individual mods |
| `guide/20-modlist.typ` | The curated modlist: foundations, rolling stock, detail mods, rejected mods with reasons |
| `guide/30-how-to-play.typ` | Field manual: career mode, jobs, licenses, locomotives, driving, the modded experience |
| `guide/40-personas.typ` | Five personas: background + game/career creation choices |

## Build the PDF

- `build-pdf.bat` → compiles to `output/Iron-Valley.pdf`
- Requires Typst 0.15+ (`winget install Typst.Typst`)
