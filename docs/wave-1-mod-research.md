### AutoDrive — NOT FOUND on ModHub
AutoDrive does not appear to have a ModHub listing for FS25. The base mod is typically available on GitHub at `github.com/Stephan-S/FS25_AutoDrive` (unverified URL). fs25.net has 280+ AutoDrive COURSES (pre-made routes for specific maps) but the base mod itself was not found in standard search. This is a critical gap — AutoDrive is essential for automated road transport between fields and sell points.

**Recommendation**: Check GitHub for FS25 AutoDrive release. If not available, CoursePlay + WayPoint GPS can partially fill the gap.

### Wine/Beer Production Summary

The core Wave 1 production chain:
- **Wine**: Grapes (from vineyard or Fruit Greenhouse) → WINERY building → Wine/Grape Juice/Mead → Sell
- **Beer**: Barley (field) + Hops (hop plantation or field) + Water → Brewery → Beer → Sell
- **Vertical Integration**: The Mechet Production Pack + WINERY + Brewery cover all production needs

1. **Le Mechet IS available for FS25** but only on fs25.net (not ModHub). It has a strong ecosystem of companion mods by the same author (Ma7).
2. **CoursePlay supports vineyards** — explicitly mentioned in GitHub changelog (Gregoire GL vine harvester support).
3. **No standalone grape harvester mod** — the "Tools for Grapes and Olives" pack covers all vineyard equipment needs.
4. **Precision Farming 3.0 is live and official** — 9,392 ratings, including new PWM sprayers and tramline guidance.
5. **AutoDrive base mod is MISSING from ModHub** — essential for automated transport. Needs GitHub verification.
6. **KingMods is dead** (404) — confirmed by multiple attempts.
7. **ModHub's search/listing pages render poorly** for automated scraping — manual browser verification recommended for final mod selection.
