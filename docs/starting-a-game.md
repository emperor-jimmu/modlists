# Starting a Modded Game

With your modlist set up and load order configured, it's time to start a new campaign. This page helps you make choices that lead to a fun, balanced experience.

## Choosing Your Origin

Origins define your empire's backstory and starting situation. With mods, even more origins become available.

**Beginner-friendly origins:**
- Prosperous Unification — well-rounded, no penalties
- Mechanist — starts with robotic workers, strong economy
- Syncretic Evolution — two species, one specialized for labor

## Galaxy Settings

| Setting | Recommendation | Notes |
|---------|---------------|-------|
| Galaxy Size | Medium (600-800 stars) | Large enough for variety, small enough for performance |
| Galaxy Shape | Spiral 4-arm | Classic, balanced |
| AI Empires | 8-10 | Enough for interesting diplomacy |
| Fallen Empires | 2 | Ancient guardians of the galaxy |
| Marauders | 1 | Mid-game raiders |
| Advanced AI Starts | 3-4 | Some empires start ahead |
| Difficulty | Ensign or Commodore | Balanced challenge |
| Crisis Strength | 1x (default) | First modded run |
| Mid-Game Year | 2300 | Standard |
| End-Game Year | 2400 | Standard |
| Victory Year | 2500 | Standard |
| Hyperlane Density | 1x (default) | More = faster travel, less chokepoints |
| Wormhole Pairs | 2 | Adds connectivity |
| Gateway Frequency | 0.5x | Late-game fast travel |

## Empire Setup for Balance

With modded content, balance is largely what you make of it. Here are some tips:

- **Ethics:** Choose a normal ethics combo (not gestalt consciousness for your first run)
- **Civics:** Pick civics that match your playstyle. Avoid anything that says +20% or more to a major resource
- **Traits:** Standard point-buy is fine. Avoid stacking multiple +resource traits

## Start Your Game

1. Launch Stellaris through MO2 (dropdown → Run).
2. Stellaris will open the Paradox Launcher.
3. Make sure your MO2 profile's mods are shown as active in the launcher.
4. Start a new game with your chosen settings.

**Important:** Some mods may prompt you with initial setup events when you first unpause. Read them carefully.
