## Notes

- **Convenient Inventory** does not add items, change prices, or alter game balance — it only reduces the tedium of inventory sorting.
- **Better Quest Rewards** makes questing more satisfying without breaking progression. Configure the multiplier in GMCM if you prefer more conservative rewards.
- **Automatic Gates** is set-and-forget — install, run once to generate config, and gates open/close as you pass through. Optionally configure delays and ignored gates via overlay or GMCM.
- **Destroyable Bushes** lets you clear unwanted bushes without needing a map editor. Bushes regrow by default, so the landscape isn't permanently altered. Configure which bush types and locations are affected in GMCM.
- **Better Shipping Bin** is purely a safety net for accidental shipping. Items can be retrieved until the day ends and they're actually sold.
- **Merchant - Become a Shopkeeper** is a complete shopkeeping minigame — you set hours, prices, and decorate your shop. Income is earned through gameplay, not given freely. Compatible with Furniture Framework for shop decoration items.
