# Gameplay Tweaks

Quality-of-life adjustments that streamline existing mechanics without adding new content.

| Mod | Purpose | Notes | Load Order |
|-----|---------|-------|------------|
| Convenient Inventory | Inventory management suite — quick stack items to nearby chests, favorite items to protect them from being trashed/shipped/stacked, auto-organize chests, take all but one from a stack, and per-chest quick-stack toggles with priority levels. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/10384) — SMAPI-based by gaussfire, 24k+ endorsements. Full Generic Mod Config Menu support. Works with Chests Anywhere, Bigger Backpack, Custom Backpack Framework, and Convenient Chests 2. Compatible with 1.6. | Below foundations |
| Better Quest Rewards | Improves and balances quest rewards — configurable multipliers and reward pools for every quest type. All settings adjustable via config file or GMCM. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/42119) — SMAPI-based, v1.1.0, 114+ endorsements. Requires SMAPI and GMCM. Tagged "Fair and balanced" — rewards are enhanced but not OP. | Below foundations, alongside other gameplay tweaks |

## Notes

- **Convenient Inventory** does not add items, change prices, or alter game balance — it only reduces the tedium of inventory sorting.
- **Better Quest Rewards** makes questing more satisfying without breaking progression. Configure the multiplier in GMCM if you prefer more conservative rewards.
