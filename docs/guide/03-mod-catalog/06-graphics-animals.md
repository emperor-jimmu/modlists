# Graphics Animals

Mods that change the appearance of your pets, farm animals, horses, and wild critters.

| Mod | Purpose | Notes | Load Order |
|-----|---------|-------|------------|
| Elle's Town Animals | Replaces nearly every creature in the valley — birds, squirrels, frogs, butterflies, Dusty, the traveling merchant's pig, and more. 42+ config options. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/1965) — CP-based, 14k+ endorsements. Each critter type is individually toggleable in config. | Below base graphics, above animal additions |
| Elle's Cuter Cats | Adds up to 155 cat breeds/skins using the 1.6 pet breed system. Breeds include Bengal, Calico, Ragdoll, Siamese, Tuxedo, and more. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/20041) — CP-based, 1.6-native. Uses the new breed feature instead of replacement. AT compatible. | Above animal replacements |
| Elle's Cuter Dogs | Adds up to 342 dog breeds/skins using the 1.6 pet breed system. Breeds include Corgi, Husky, Golden Retriever, Shiba Inu, and more. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/20040) — CP-based, 1.6-native. Void variants included. AT compatible. | Same as Cuter Cats |
| Elle's Cuter Horses | 79 horse skins with a choice of breed, saddle colour, and optional prismatic hair overlay. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/20042) — CP-based. Standard texture replacement (no breed system for horses). Includes horse flute recolor. | Above other horse mods |
| SH's Wild Animals | Adds new wild animals to the world — squirrels, foxes, ducks, turtles, otters, platypuses, and more. Appear based on time, weather, and season. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/9063) — CP-based. Main version includes SVE content; use the Lite version if not playing with SVE. May have minor performance impact with many animals on screen. | Load last in animal section |

## Notes

- **Elle's Town Animals** replaces existing critters; **SH's Wild Animals** adds new ones. They complement each other rather than conflict.
- **Elle's Cuter Cats/Dogs** use the 1.6 breed system, which adds options rather than replacing sprites. On existing saves, use the debug command `debug cmenu` to change your first pet's appearance.
- **SH's Wild Animals** can cause lag on lower-end systems due to the number of active critters. Reduce the spawn rate in config if needed.
- For barn/coop animal skins, see [Elle's Cuter Barn Animals](https://www.nexusmods.com/stardewvalley/mods/20044) and [Elle's Cuter Coop Animals](https://www.nexusmods.com/stardewvalley/mods/20043) — companion mods from the same author.
