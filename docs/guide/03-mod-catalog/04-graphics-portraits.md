# Graphics Portraits

Portrait replacements that change how NPCs look in dialogue and menu screens.

| Mod | Purpose | Notes | Load Order |
|-----|---------|-------|------------|
| mono's Portraits | A full portrait replacement for all vanilla villagers and marriage candidates, drawn at native scale with a faithful but distinct style. Includes winter outfits for 1.6. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/16649) — CP-based, updated for 1.6. Does not cover modded NPCs. | Anywhere in graphics section |
| They Deserve It Too - Portraits for Extras | Adds custom dialogue portraits to 40+ extra characters who don't normally have portraits — vendors, event NPCs, tourists. Automatically adjusts for supported companion mods. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/35358) — CP-based, requires CP + GMCM. Does not conflict with full portrait replacements (covers different NPCs). Part of the They Deserve It Too series. | Below full portrait replacements |
| Seasonal Outfits - Slightly Cuter Aesthetic | Overhauls all NPC sprites and portraits with seasonal outfits — one per season plus festival costumes (spouses get full coverage). Farmer can also wear seasonal clothes. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/5450) — CP-based, 24k+ endorsements. Requires CP + GMCM. Compatible with SVE and East Scarp (separate add-on packs). Conflicts with mono's Portraits — only one full portrait/sprite mod per NPC can be active. | Replaces mono's Portraits if using this mod |

## Notes

- Only one portrait mod can be active at a time per NPC. Choose one set that fits your preferred art style.
- Seasonal outfit variants (like mono's winter outfits) require the mod's config to be set correctly.
- **They Deserve It Too** covers characters without portraits and works alongside any full portrait replacement.
- **Seasonal Outfits - Slightly Cuter Aesthetic** replaces both sprites and portraits — if you use it, disable mono's Portraits for the affected NPCs.
