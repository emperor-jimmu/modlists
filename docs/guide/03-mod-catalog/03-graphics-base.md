# Graphics Base

Base graphical overhauls that change buildings, paths, fences, and interior/exterior structures.

| Mod | Purpose | Notes | Load Order |
|-----|---------|-------|------------|
| Medieval Buildings | Full set of seasonal farm buildings — barns, coops, silos, sheds, etc. Multiple style options. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/4542) — CP-based. 32k+ endorsements. Pairs with Way Back Pelican Town for matching town buildings. | Above terrain/foliage mods |
| Way Back Pelican Town | Seasonal retexture of all town buildings, structures, and decor (including Desert + Ginger Island). | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/7332) — CP-based, tagged 1.6 Compatible. By Gweniaczek. Not fully compatible with SVE town map. | Same as Medieval Buildings |
| Gwen's Paths | Retextures/recolours of all craftable paths and floorings. CP and AT versions available. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/8683) — Each path type toggleable in config. Matches Medieval Buildings aesthetic. | Below building mods |
| Cottagecore Fences | Seasonal retexture of wood, stone, iron, and hardwood fences. Adds vines, moss, and petals. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/8558) — CP-based, confirmed 1.6 compatible. Also available as an AT pack. | Same as paths |
| Cuter Coops and Better Barns | Slightly larger, redecorated interiors for coops and barns. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/4226) — CP-based. Changes interior maps — incompatible with other mods that modify barn/coop maps. | Below base graphics, above animal mods |
| Rustic Country Town Interiors | Recolors and redesigns town interiors, spouse rooms, and farm building interiors with seasonal decoration. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/6098) — The official version is lagging behind 1.6. An [unofficial 1.6 update](https://www.nexusmods.com/stardewvalley/mods/21210) is available. Alternative: [DaisyNiko's Earthy Interiors](https://www.nexusmods.com/stardewvalley/mods/14790) is officially updated for 1.6. | Before farmhouse interior mods |

## Notes

- **Medieval Buildings** and **Way Back Pelican Town** are designed as a matching set (farm + town). You can mix them with other terrain recolours.
- **Cuter Coops and Better Barns** changes interior map dimensions — do not use with other mods that alter barn/coop maps.
- For **Rustic Country Town Interiors**, prefer the unofficial 1.6 update or Earthy Interiors for 1.6 compatibility.
