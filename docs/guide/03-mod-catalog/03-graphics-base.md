## Notes

- **Medieval Buildings** and **Way Back Pelican Town** are designed as a matching set (farm + town). You can mix them with other terrain recolours.
- **Cuter Coops and Better Barns** changes interior map dimensions — do not use with other mods that alter barn/coop maps.
- For **Rustic Country Town Interiors**, prefer the unofficial 1.6 update or Earthy Interiors for 1.6 compatibility.
- **Fashion Sense clothing/hair packs** all require the Fashion Sense framework (in Foundations). They can be mixed freely — Fashion Sense supports unlimited content packs simultaneously. Use the Hand Mirror tool (purchasable from Pierre or start with it during character creation) to equip items.
- **Furniture mods** that add new items require their respective frameworks (Calcifer for Green Grove, Furniture Framework for Retro Style). Nostalgic Old Furniture and Myc's Seasonal Fireplace work with CP alone.
- Most furniture mods add their own catalogue purchasable from Robin's shop. Items can also be spawned via CJB Item Spawner if preferred.
