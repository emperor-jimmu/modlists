## Notes

- **Medieval Buildings** and **Way Back Pelican Town** are designed as a matching set (farm + town). You can mix them with other terrain recolours.
- **Nano's Countryside Farm Buildings** uses Alternative Textures (AT) rather than CP — this means it can coexist with CP-based retextures like Medieval Buildings or Elle's Seasonal Buildings (apply via Paint Bucket per-building).
- **Elle's Seasonal Buildings** offers seasonal vanilla-faithful buildings with 7 colour palettes to match your chosen terrain recolor. Use it instead of Medieval Buildings if you prefer a seasonal vanilla look. Pairs naturally with Earthy Recolour.
- **HxW Custom Buildings** adds entirely new building shapes rather than retexturing existing ones — it works alongside any building retexture mod.
- **Cuter Coops and Better Barns** changes interior map dimensions — do not use with other mods that alter barn/coop maps.
- **Path/flooring retextures** (Gwen's Paths, Lun's Paths, Seasonal Path and Flooring) are mutually exclusive — pick one set that matches your preferred aesthetic. Gwen's Paths pairs with Medieval Buildings; Lun's Paths offers a witchy/cottagecore look; Seasonal Path and Flooring adds seasonal detail.
- **Dynamic Reflections** is a visual-only framework — it does not change gameplay or add items. Configurable via config.json for performance: adjust reflection tick interval, disable throttling, or toggle specific reflection types (water, mirror, map tiles). Lower-end systems should set a higher tick interval.
- **Fashion Sense clothing/hair packs** all require the Fashion Sense framework (in Foundations). They can be mixed freely — Fashion Sense supports unlimited content packs simultaneously. Use the Hand Mirror tool (purchasable from Pierre or start with it during character creation) to equip items.
- **Furniture mods** that add new items require their respective frameworks (Calcifer for Green Grove, Furniture Framework for Retro Style). Nostalgic Old Furniture and Myc's Seasonal Fireplace work with CP alone.
- Most furniture mods add their own catalogue purchasable from Robin's shop. Items can also be spawned via CJB Item Spawner if preferred.
- **Tool/weapon retextures** (Grandpa's Tools, Magical Valley) are mutually exclusive — they replace the same textures. Grandpa's Tools has a weathered medieval aesthetic; Magical Valley has a pink pastel magical theme.
- **Quaint Living - Buildings** has an overgrown/cottage aesthetic distinct from other building mods. It can complement or replace Medieval Buildings or Elle's Seasonal Buildings depending on your preferred look.
- **Cornucopia Trees Retextured** requires Cornucopia - More Crops (in 14-farming-and-making.md). It only replaces tree sprites that aren't already hand-drawn in the base Cornucopia mod.
