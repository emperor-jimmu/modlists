# Alternates & Conflicts

Mods that conflict with or serve as alternatives to the main catalog picks. Not included in the primary guide, but documented here for reference.

| Mod | Purpose | Why It's Here | Notes |
|-----|---------|---------------|-------|
| Fancy Artisan Goods Icons Retexture | Retextures artisan goods item sprites (jellies, wines, cheeses, etc.) with a fancier look. | **Conflicts** with DSHi Shipping Items Retexture — both are CP-based and target the same item sprites. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/12766) — CP-based. Alternative to the DSHi shipping items set if you prefer ornate icons over DSHi's clean style. Install one or the other, not both. |

| Fancy Crops and Forage Retexture | Retextures crops, forage, and seed packets with a fancier, fresher look. Includes SVE crops and forage support. | **Conflicts** with DSHi Shipping Items Retexture — both are CP-based and target the same crop/forage sprite sheets. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/14070) — CP-based by Aimon111, v2.0 (Mar 2024), 1.4k+ endorsements. 1.6 compatible. Highly configurable (enable/disable per category). Alternative to DSHi's clean uniform approach for a more ornate icon style. |
| Fancy Rings and Shoes Retexture | Retextures all vanilla rings and shoes with a fresh, fancy look. Does not cover combined rings. | **Conflicts** with Better Rings — both are CP-based and target ring sprite sheets. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/14122) — CP-based by Aimon111, v1.0.0 (Oct 2022), 574+ endorsements. 1.6 compatible. Also retextures shoes, which Better Rings does not cover. Note: combined rings may display incorrectly — disable the component rings in config when using the forge. |

## Notes

- **CP-based sprite retextures** that target the same asset sheets are mutually exclusive. The last loaded mod wins.
- When choosing between conflicting mods, pick the aesthetic that best matches your overall visual theme (e.g., DSHi's clean uniform style vs. Fancy Artisan Goods' ornate look).
- The **Aimon111 "Fancy" series** (Fancy Crops, Fancy Rings, Fancy Trash, Fancy Elixirs) shares a consistent ornate visual style. Fancy Elixirs is in the primary catalog as it has no conflicting catalog pick; the others are listed here if you prefer that aesthetic over the DSHi/Better Rings picks.
