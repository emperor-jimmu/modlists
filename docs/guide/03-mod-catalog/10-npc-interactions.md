## Notes

- **Tilly** is a full custom NPC with marriage support, heart events, and a custom location. Install all required dependencies (BETAS, Midnight's Misc Tilesheets) before adding this mod.
- **Adventurer's Guild Expanded** was ported to CP-only for 1.6 — the original required Json Assets and SAAT. The 1.6 version bundles custom music and runs entirely on Content Patcher. Compatible with East Scarp (v2.3.2+ includes ES compatibility fixes).
- **Willy Expansion** adds content for Willy and Elliott without altering core logic. Pairs well with Aquatic Sea Fish for extra fishing depth.
- Only one portrait mod per NPC can be active at a time. Tilly and Adventurer's Guild Expanded both include optional Nyapu-style portrait support.
- **Daulton and Maple** is a full custom NPC with SVE compatibility. Works alongside Tilly, Adventurer's Guild Expanded, and other custom NPCs without conflict (different NPCs).
- **A Little More Cutscenes** adds 22 events across the game. Not fully compatible with SVE — some events are disabled if SVE is installed due to map changes. A new save is recommended for ideal event triggering.
- **Happy Birthday** requires two separate downloads — the main mod (520) and a language content pack (11148 for English, others available). Install both. Requires Stardust Core (2341) as a framework dependency.
- **Date Night Redux** is a continuation of the original Date Night mod with bug fixes, i18n support, and no Event Repeater dependency. Generic dates are available for all spouses; Alex, Haley, Emily, and Maru have spouse-specific dates. Other spouses get random generic dates.
- **Juliet and Jessie** have a standalone version and an East Scarp-bundled version. The standalone version (this one) is for players not using East Scarp. If you use East Scarp 3.0+, do NOT install this mod — Juliet and Jessie are included in East Scarp natively.
- **Romanceable Rasmodia** is not romanceable on its own — it requires either Stardew Valley Expanded (which adds romanceable Wizard via the Wizard's 14-heart event) or Romanceable Rasmodius (21607) to unlock marriage. Without either, Rasmodia is purely a cosmetic gender-swap of the Wizard.
- **Mal's Sebastian Expansion** is spouse-specific — it only affects Sebastian. It is compatible with other Sebastian dialogue mods but may have dialogue overlap. The non-smoking version uses a separate sprite by Prismuth. Events 3 and 7 require config edits to enable.
- **More Spouse Events** covers all 12 vanilla marriage candidates. It does not cover modded NPCs or SVE spouses. Events trigger based on heart level, farmhouse upgrade, season, and time conditions — see each event's trigger conditions on the mod page.
