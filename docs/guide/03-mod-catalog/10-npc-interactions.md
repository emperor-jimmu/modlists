## Notes

- **Tilly** is a full custom NPC with marriage support, heart events, and a custom location. Install all required dependencies (BETAS, Midnight's Misc Tilesheets) before adding this mod.
- **Adventurer's Guild Expanded** was ported to CP-only for 1.6 — the original required Json Assets and SAAT. The 1.6 version bundles custom music and runs entirely on Content Patcher. Compatible with East Scarp (v2.3.2+ includes ES compatibility fixes).
- **Willy Expansion** adds content for Willy and Elliott without altering core logic. Pairs well with Aquatic Sea Fish for extra fishing depth.
- Only one portrait mod per NPC can be active at a time. Tilly and Adventurer's Guild Expanded both include optional Nyapu-style portrait support.
- **Daulton and Maple** is a full custom NPC with SVE compatibility. Works alongside Tilly, Adventurer's Guild Expanded, and other custom NPCs without conflict (different NPCs).
- **A Little More Cutscenes** adds 22 events across the game. Not fully compatible with SVE — some events are disabled if SVE is installed due to map changes. A new save is recommended for ideal event triggering.
