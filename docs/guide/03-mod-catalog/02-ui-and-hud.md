## Notes

- **NPC Map Locations** and **Lookup Anything** are standalone QoL mods that work well together — use F1 to look up an NPC, then check the map to find them.
- **Lookup Anything** has a configurable progression mode — enable it in Generic Mod Config Menu to preserve the discovery experience for gift tastes and recipes.
- **UI Info Suite 2** is a comprehensive info suite. Its NPC map feature is automatically disabled when NPC Map Locations is installed (the dedicated map mod takes priority). All features can be individually toggled in Generic Mod Config Menu if you prefer a more curated set of info displays.
- **To-Dew** and **Social Page Order Redux** are lightweight QoL mods that don't interact with other UI mods.
- **DaisyNiko's Earthy Interface** is designed to pair with DaisyNiko's Earthy Recolour (see 05-graphics-terrain.md) for a cohesive earthy aesthetic. Only use one full UI theme at a time.
