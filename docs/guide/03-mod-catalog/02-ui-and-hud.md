# UI and HUD

Quality-of-life interface improvements and visual UI overhauls.

| Mod | Purpose | Notes | Load Order |
|-----|---------|-------|------------|
| NPC Map Locations | Shows the current location of every NPC on the world map. Hover over an icon to see their name; check the tooltip for their current schedule status. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/239) — CP-based, 85k+ endorsements. Does not reveal schedules ahead of time — only shows current position. Compatible with 1.6. | Below foundations, above content mods |
| Lookup Anything | Press F1 to see live info about whatever's under your cursor — crop harvest times, machine output, NPC gift tastes, animal happiness, fence durability, and more. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/541) — SMAPI-based by Pathoschild, 193k+ endorsements. Updated for 1.6.15. Includes a **progression mode** (optional) that hides gift tastes until you've learned them naturally. Works in single-player and multiplayer. | After foundations, alongside other UI mods |
| DaisyNiko's Earthy Interface | Complete UI recolor with warm earthy tones — menus, dialogue boxes, inventory, shipping menu, calendar, and more. Matches the Earthy Recolour terrain palette. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/13658) — CP-based by DaisyNiko, 20k+ endorsements. Companion to DaisyNiko's Earthy Recolour and Earthy Interiors. Compatible with 1.6. Toggle individual elements in config. | After other UI mods |

## Notes

- **NPC Map Locations** and **Lookup Anything** are standalone QoL mods that work well together — use F1 to look up an NPC, then check the map to find them.
- **Lookup Anything** has a configurable progression mode — enable it in Generic Mod Config Menu to preserve the discovery experience for gift tastes and recipes.
- **DaisyNiko's Earthy Interface** is designed to pair with DaisyNiko's Earthy Recolour (see 05-graphics-terrain.md) for a cohesive earthy aesthetic. Only use one full UI theme at a time.
