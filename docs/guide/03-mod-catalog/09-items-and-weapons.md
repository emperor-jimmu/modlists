## Notes

- All items in this section are **purely cosmetic** — they replace sprite textures only and do not affect stats, recipes, or game mechanics.
- The **DSHi series** (5 mods) is designed as a cohesive set. Install all of them for a consistent visual style across every item category, or pick individual packs for specific item types. Load them in the order listed above.
- **Better Rings** can be used alongside the DSHi mods — they change different item categories.
- **Fancy Vanilla and SVE Elixirs Retexture** is independent of the DSHi series — it targets elixir/potion sprites that DSHi does not cover. Compatible with all other item retextures.
- No Content Patcher conflicts between these mods — each targets distinct sprite sheets.
- **Animated Gemstones** animates gems, minerals, geodes, and nodes. It can coexist with the DSHi mineral retextures (DSHi provides the static sprites, Animated Gemstones adds the animation overlay). The config file lets you disable individual gem animations if you prefer the DSHi static look for specific items.
- **Animated Fish SVE** only works if **Stardew Valley Expanded** is installed. It is part of a broader "Animated Fish" series by Gervig91 that also covers vanilla fish (5735), Ridgeside Village fish (7353), East Scarp fish (10913), and More New Fish (5845). Each is independent and targets only the fish from its respective mod.
