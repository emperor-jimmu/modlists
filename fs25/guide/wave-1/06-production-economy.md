# Wave 1 — Production & Economy

Mods added in this wave beyond Wave 0.

## Wine & Beer Production Chains

Wave 1's core production loop:

```
Grapes (vineyard/Fruit Greenhouse) ─→ WINERY ─→ Wine / Grape Juice / Mead
Barley (field) + Hops (plantation) + Water ─→ Brewery ─→ Beer
```
