# Mod Development Ideas

Mods that don't exist yet for FS25 but would significantly improve the modlist.

## Follow Me (FS25 Port)
- **Purpose**: Vehicle following — one worker follows another vehicle automatically. Essential for harvest + transport operations.
- **Wave**: All waves
- **Why it's missing**: FS22 version by Decker_MMIV has not been ported to FS25. No alternative exists.
- **Notes**: CoursePlay provides partial workaround (multi-vehicle coordination) but is heavier. A lightweight Follow Me mod would be ideal for Wave 0 beginners.

## Enhanced Vehicle HUD / Vehicle Control Addon (FS25 Port)
- **Purpose**: Real-time vehicle data display — RPM, fuel level, speed, fill levels, engine temperature. Displayed as a HUD overlay.
- **Wave**: All waves
- **Why it's missing**: The FS22 VCA mod has not been ported to FS25. This is the most-requested missing QoL mod.
- **Notes**: Enhanced Vehicle (fs25.net) provides some vehicle management but no HUD overlay. "Radial Vehicle Switcher" provides vehicle switching but not data display.

## Relight (FS25 Port)
- **Purpose**: Dynamic lighting overhaul — natural sunrises/sunsets, adjustable ambient light, realistic shadows.
- **Wave**: All waves
- **Why it's missing**: FS22 lighting overhaul not ported. No FS25 alternative exists.
- **Notes**: Reshade can partially compensate with color correction and levels, but does not affect in-game lighting engine. Oak Bridge Farm and Le Mechet maps include custom lighting as a partial fix.

## AutoDrive Base Mod (FS25 Version)
- **Purpose**: Automated road transport between fields, sell points, and production buildings. Generates and follows GPS road routes.
- **Wave**: All waves (especially Wave 2)
- **Why it's missing**: 280+ per-map AutoDrive COURSES exist on fs25.net, indicating the base mod IS widely used, but the base mod was not found on ModHub or with a verified download link.
- **Notes**: May exist on GitHub (`github.com/Stephan-S/FS25_AutoDrive` — unverified URL). Needs proper listing on ModHub or a verified download source. WayPoint GPS provides lightweight alternative.

## FS25 Reshade Preset Collection
- **Purpose**: Curated Reshade presets specifically designed for Farming Simulator 25's lighting and color palette.
- **Wave**: All waves
- **Why it's missing**: Nexus Mods FS25 section (132 mods) has zero Reshade presets. No community presets published.
- **Notes**: Generic Reshade presets exist but are not tuned for FS25's agricultural environment. Presets should account for direct sunlight, field colors, and vehicle reflections.

## Fleet Manager Mod
- **Purpose**: Dedicated fleet management UI — group vehicles by type, track maintenance schedules, monitor fuel levels, assign workers to specific vehicles.
- **Wave**: Wave 2
- **Why it's missing**: Vehicle Manager (ModHub #368590) and Enhanced Vehicle (fs25.net) provide partial features but no dedicated fleet management UI exists.
- **Notes**: Production Manager by NXModding provides similar functionality for production buildings. A vehicle-focused equivalent would complement it.

## Dedicated Grape Harvester Mod
- **Purpose**: A standalone grape harvester with detailed model, animations, and FS25 v1.20.0.0 support.
- **Wave**: Wave 1
- **Why it's missing**: No standalone grape harvester on ModHub. "Tools for Grapes and Olives" pack includes one but as part of a larger pack. Base game Gregoire GL exists but lacks the polish of a dedicated mod.
- **Notes**: CoursePlay has explicit Gregoire GL support. A modded grape harvester would benefit from CoursePlay compatibility.

## Semi Truck / Transport Mod Pack
- **Purpose**: Dedicated semi trucks (Peterbilt, Kenworth, Freightliner) with trailer hitches for FS25's cargo system.
- **Wave**: Wave 2
- **Why it's missing**: Semi truck mods exist on ModHub but no standout pack with multiple models and verified v1.20.0.0 compatibility. Mack Pinnacle and Camara trailers are available individually.
- **Notes**: Rail mods (North American Trains, JWeezy Train Mod) provide alternative bulk transport.
