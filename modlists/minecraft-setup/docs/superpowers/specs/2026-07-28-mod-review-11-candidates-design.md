# Mod Review — 11 Candidates (Jul 2026)

**Status**: Design — approved  
**Date**: 2026-07-28  
**Scope**: Review 11 mod candidates for inclusion in the Driftwood modpack

## Decisions

| Mod | Verdict | Wave | Reasoning |
|-----|---------|------|-----------|
| Traveler Tool Belt | **ADDED** | Wave 0.5 — Player Experience | Tool radial menu (R key), 2→9 slots via upgrades, Curios integration. Clean QoL addon, no conflicts. By Tiviacz1337. NeoForge 26.1.2-1.0.2 |
| Field Guide | **ADDED** | Wave 2 — Exploration | Spyglass-based creature/plant/monster catalog. Exploration doc mod. No dependencies, no gameplay impact. By evanbones. NeoForge 26.1.2-1.7.7 |
| Create Deep Seas | **ADDED** | Wave 1 — Create Addons | Create-based underwater automation. Pairs with Upgrade Aquatic + Hybrid Aquatic (Wave 2). By MaxCreateMC. NeoForge 1.21.1 |
| Kaleidoscope Tavern | **SKIPPED** | — | Standalone barrel brewing. Overlaps with Brewin' And Chewin' (FD ecosystem). FD integration is more valuable for the pack's progression. By TartaricAcid |
| Kaleidoscope World Liquor | **SKIPPED** | — | Alcoholic drinks addon. Overlaps with Brewin' And Chewin'. Too niche. By ChenjdyUltra |
| Kaleidoscope Dimensions Wine | **SKIPPED** | — | Dimension-specific wines. Overlaps with Brewin' And Chewin'. Too niche. By wither_redstone |
| Create: Gears and Tavern | **SKIPPED** | — | Create-themed tavern addon. Overlaps with Brewin' And Chewin' + Kaleidoscope Tavern. By yision1 |
| Create Aeronautics | **SKIPPED** | — | Create-based vehicles (airships, cars). Requires Sable dependency. Known incompatibilities. Current flight progression (Glider → Ornithopter → Immersive Aircraft) already covers flight adequately. By ryanhcode |
| Trek Mod | **SKIPPED** | — | 150+ structures data pack. Overlaps with YUNG's collection (10 mods) + Structory already in pack. By hotsuop_old |
| TarotCards: Remastered | **SKIPPED** | — | 22 Major Arcana cards with buffs/debuffs. RNG RPG flavor. Overlaps with Apotheosis gems/runes and existing equipment ecosystem. By Suel_ki |
| Create: Stats & Additions | **SKIPPED** | — | Create addon with stat-boosting equipment. Need more detail but uncertain overlap with Create Crafts & Additions. By CobanF8 |
