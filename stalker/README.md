# G.A.M.M.A Protocol — README

Modlist and game guide for **S.T.A.L.K.E.R. Anomaly 1.5.3** with the **GAMMA** modpack. The guide covers installing Anomaly, installing GAMMA on top of it, a detailed how-to-play field manual, and community addons.

## What's inside

| File | Content |
|---|---|
| `guide/10-installation.typ` | Anomaly 1.5.3 install (ModDB) → GAMMA install (official launcher) |
| `guide/20-modlist.typ` | The GAMMA pack: systems, difficulty/progression presets |
| `guide/30-how-to-play.typ` | Detailed game guide: survival, combat, repair/crafting, economy |
| `guide/40-addons.typ` | Community addons and how to install them safely |

## Build the PDF

- `build-pdf.bat` → compiles to `output/G.A.M.M.A-Protocol.pdf`
- Requires Typst 0.15+ (`winget install Typst.Typst`)
