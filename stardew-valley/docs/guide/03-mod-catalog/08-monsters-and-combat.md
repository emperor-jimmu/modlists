# Monsters and Combat

Quality-of-life improvements and visual tweaks for monster encounters.

| Mod | Purpose | Notes | Load Order |
|-----|---------|-------|------------|
| Mini Bars | Adds customizable health bars above monsters. Shows remaining HP at a glance; supports different bar themes (mini/long), range-limiting, and toggle for showing only damaged enemies. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/8329) — SMAPI-based by GukelZ, 9.5k+ endorsements. Configurable via Generic Mod Config Menu or in-game commands. Compatible with Ridgeside Village and Swim mods. Updated for 1.6. | Below foundations |

| Animated Slime Eggs and Loot | Animates slime eggs, geodes, gem nodes, ingots, ores, and monster loot sprites. Sharpens gemstone/crystal appearances with subtle movement. Configurable per-item toggles. | [NexusMods](https://www.nexusmods.com/stardewvalley/mods/5642) — CP-based, v2.2.0, 2.5k+ endorsements. Requires CP, SMAPI, and SpaceCore. Config file allows enabling/disabling each animation individually. 1.6 compatible. Companion to Animated Gemstones mod (see Items and Weapons). | Below foundations, alongside other item animation mods |

## Notes

- **Mini Bars** is purely informational — it does not change monster stats or behaviour.
- **Animated Slime Eggs and Loot** covers monster-related items (slime eggs, bat wings, void essence, solar essence) while **Animated Gemstones** (in 09-items-and-weapons.md) covers gems, minerals, and geodes. They share the same author's visual style and can be used together.
