## Notes

- **NPC Map Locations** and **Lookup Anything** are standalone QoL mods that work well together — use F1 to look up an NPC, then check the map to find them.
- **Lookup Anything** has a configurable progression mode — enable it in Generic Mod Config Menu to preserve the discovery experience for gift tastes and recipes.
- **UI Info Suite 2** is a comprehensive info suite. Its NPC map feature is automatically disabled when NPC Map Locations is installed (the dedicated map mod takes priority). All features can be individually toggled in Generic Mod Config Menu if you prefer a more curated set of info displays.
- **To-Dew** and **Social Page Order Redux** are lightweight QoL mods that don't interact with other UI mods.
- **DaisyNiko's Earthy Interface** is designed to pair with DaisyNiko's Earthy Recolour (see 05-graphics-terrain.md) for a cohesive earthy aesthetic. Only use one full UI theme at a time.
- **Zoom Level** is a standalone tool that complements other UI mods — it does not change the appearance of any UI element, only the scale. Works alongside UI Info Suite 2 and NPC Map Locations without conflicts. The camera position controls are useful for screenshotting or exploring maps beyond the normal viewport.
- **Community Center Icons Redone** is a purely visual replacement — it only changes bundle icon sprites in the Community Center menu. Compatible with all UI mods since it targets a different asset sheet than interface recolours.
- **Vintage Interface v2** is an alternative to DaisyNiko's Earthy Interface — pick one full UI theme. It has been **unmaintained since June 2022**, so compatibility with future SDV updates is not guaranteed. Its CP-based asset replacement approach may work on 1.6 but has not been officially tested. Keep this in mind when updating your game.
