# Modlist - Wave 2

<span class="wave-badge wave-2">Wave 2</span>

**Roleplay**: *Master Witcher* - You no longer follow the Path - you define it. Every fight is a lesson, every monster a testament to your mastery.

## Includes All Wave 0 and Wave 1 Mods + The Following:

## Installation Instructions

1. Open Witcher 3 Mod Manager
2. Select your "Wave 2" profile (create it via *Upgrading to Wave 2*)
3. Install each mod below in order
4. Run Script Merger - **mandatory**: Wave 2 is script-heavy and every mod below edits game scripts
5. Verify load order against the [Load Order Guide](../03-reference/02-load-order)
6. Start a **New Game or New Game+** - Spectre must not be installed into an existing save

> **Warning**: Wave 2 is intended for players who have completed the main game and both expansions at least once. Eternal Hunt is explicitly **not** for first playthroughs.

### Alternatives Considered (not included)

These verified mods deliver similar effects but must **not** be stacked with the picks above:

- **Combat Redux** ([#8515](https://www.nexusmods.com/witcher3/mods/8515)) - souls-like stamina combat (attacks and dodges consume stamina, Sign nerfs). Alternative combat core - do not stack with Eternal Hunt.
- **Blood And Steel** ([#9674](https://www.nexusmods.com/witcher3/mods/9674)) - combat animation layer, explicitly incompatible with mods that change attack animations (Eternal Hunt).
- **Lore-Friendly Economy** ([#7691](https://www.nexusmods.com/witcher3/mods/7691)) - price/loot deflation. Alternative economy overhaul - do not stack with Spectre.
- **W3EE Redux** (Witcher 3 Enhanced Edition Redux) - the iconic total overhaul, but its distribution is no longer reliably hosted on Nexus Mods, so it is excluded in favor of the actively maintained Eternal Hunt + Spectre pair.
