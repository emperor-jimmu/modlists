# Upgrading to Wave 2

<span class="wave-badge wave-2">Wave 2</span>

**Roleplay**: *Master Witcher* - You have seen horrors beyond counting and walked paths few dare tread. The old ways must be reforged. These mods reshape the very fabric of witchering.

## Upgrading from Wave 1

1. Open Witcher 3 Mod Manager
2. Create a new profile "Only Monsters Remain - Wave 2"
3. Copy Wave 1 mods to the new profile
4. Install Wave 2 mods (listed below)
5. Run Script Merger
6. Verify load order against the [Load Order Guide](../03-reference/02-load-order)
7. Start a **New Game+** or fresh save

## New in Wave 2

- **Gameplay overhauls** - combat, progression, economy
- **Mechanics changes** - new systems, rebalanced difficulty
- **Immersive features** - survival elements, realism tweaks
- **Difficulty rebalance** - intended for experienced players
