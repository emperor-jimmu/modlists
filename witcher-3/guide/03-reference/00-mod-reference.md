## Legend

- **Utilities** - mod manager, script merger, framework mods, manual install tools
- **Graphics** - textures, lighting, weather, visual effects
- **Content** - new quests, locations, and story content
- **UI / QoL** - interface and convenience improvements
- **Overhaul / Combat / Difficulty** - gameplay-changing mods (Wave 2 only)
