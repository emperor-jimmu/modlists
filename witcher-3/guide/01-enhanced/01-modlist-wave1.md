# Modlist - Wave 1

<span class="wave-badge wave-1">Wave 1</span>

**Roleplay**: *A Witcher's Journey* - The world is richer and more dangerous than you first believed. These mods reveal what was always there, hiding in plain sight.

## Includes All Wave 0 Mods + The Following:

## Installation Instructions

1. Open Witcher 3 Mod Manager
2. Select your "Wave 1" profile (create it via *Upgrading to Wave 1*)
3. Install each mod below in order
4. Run Script Merger if prompted (required for the script-based mods marked below)
5. Launch the game

> **Performance note**: Wave 1 includes graphics mods that may impact performance. If you experience frame rate drops, disable the most demanding mods first (lighting, HD texture packs) rather than lowering in-game settings significantly.
