# Upgrading to Wave 1

<span class="wave-badge wave-1">Wave 1</span>

**Roleplay**: *A Witcher's Journey* - You've walked the Path long enough to know your craft. The Continent's beauty and horrors alike deserve to be seen in full detail. New adventures await beyond the horizon.

## Upgrading from Wave 0

1. Open Witcher 3 Mod Manager
2. Create a new profile "Only Monsters Remain - Wave 1"
3. Copy Wave 0 mods to the new profile
4. Install Wave 1 mods (listed below)
5. Run Script Merger
6. Verify load order against the [Load Order Guide](../03-reference/02-load-order)

## New in Wave 1

- **Graphics enhancements** - textures, lighting, visual fidelity
- **Content additions** - new quests, gear, items, NPCs
- **UI improvements** - enhanced HUD, inventory, map

## System Requirements Note

Wave 1 includes graphics mods that may impact performance. Adjust settings as needed.
