# Enhanced Liberty — GTA IV Modlist Design

## Overview

**Enhanced Liberty** is a curated modlist and game guide for GTA IV version 1.0.8.0 (November 29, 2016 patch). It uses FusionFix (latest, pinned to a tested version) as the base compatibility framework. The modlist is organized into two waves, each with a roleplaying story theme, progressive difficulty, and a fresh new-game setup.

## Waves

### Wave 0 — "Fresh Off the Boat"

- **Story theme:** New immigrant arrives in Liberty City with no connections or reputation
- **Mod scope:** UI & QoL only (map improvements, bug fixes, vanilla-enhancing)
- **Guide content:** Complete how-to-play — controls, driving, phone, missions, wanted system, combat, economy
- **Mechanics:** No game-mechanic-changing mods

### Wave 1 — "City of Dreams"

- **Story theme:** Character has built a reputation and now operates in the criminal underworld
- **Mod scope:** Graphics, more content, new mechanics (advanced)
- **Guide content:** Advanced strategy — mission optimization, vehicle selection, weapon strats, money management, FusionFix tweaks

### Wave Transition Rules

- Each wave starts on a **fresh save file** — no save carry-over between waves
- Wave 0 mods are not required to remain installed for Wave 1
- Players must complete Wave 0 (or equivalent game experience) before starting Wave 1
- FusionFix is always installed per wave instructions regardless of wave

## FusionFix Versioning

- FusionFix is pinned to a **specific tested version** (e.g., `v3.18.0`) in all installation instructions
- Version is tracked in `01-installation.md` and updated only after testing a new release
- "Latest" is never used without a pinned fallback

## Markdown-to-Typst Pipeline

### Problem

Typst's native `.typ` markup is markdown-like but not identical: headings use `=` not `#`, bold is `*` not `**`, italic is `_` not `*`. You cannot `#include` a `.md` file directly.

### Solution: Two-step build

1. **`src/convert.js`** — a Node.js script that:
   - Reads each `guide/*.md` file
   - Converts markdown syntax to Typst markup:
     - `#` → `=` (heading 1)
     - `##` → `==` (heading 2)
     - `###` → `===` (heading 3)
     - `**text**` → `*text*` (bold)
     - `*text*` → `_text_` (italic), with guard against doubling bold markers
   - Writes each to `src/chapters/*.typ`
2. **`typst compile`** — compiles the main `.typ` entry point that `#include`s each chapter

### Build Command (`build-pdf.bat`)

```bat
@echo off
node src/convert.js
typst compile src/enhanced-liberty.typ output/Enhanced-Liberty.pdf
echo PDF generated: output/Enhanced-Liberty.pdf
```

Only a `.bat` file is provided. No `.ps1` alternative to avoid redundancy.

### How `src/enhanced-liberty.typ` works

```typst
#include "template.typ"
#include "chapters/01-installation.typ"
#include "chapters/02-wave-0-mods.typ"
#include "chapters/03-wave-0-guide.typ"
#include "chapters/04-wave-1-mods.typ"
#include "chapters/05-wave-1-guide.typ"
#include "chapters/06-fusionfix-config.typ"
```

Chapter `.typ` files are generated by `convert.js` and are gitignored (`.gitignore` entry: `src/chapters/`). The `.md` files in `guide/` are the authoritative source.

## PDF Theme (`template.typ`)

### Color Palette

- Background: dark midnight-blue (`#0d1117`) with light text for cover
- Body text: near-black (`#1a1a1a`) on off-white (`#f5f0e8`)
- Accent: Liberty City gold (`#d4a843`)
- Headings: dark steel (`#1a2530`)
- Links: deep teal (`#1a7a7a`)
- System-impact badges: orange (`#e67e22`) with white text

### Typography

- Body: `Linux Libertine` or `Noto Serif` (serif, readable at small sizes)
- Headings: `Fira Sans` or `Roboto` (sans-serif, bold)
- Code/monospace: `JetBrains Mono`
- Page numbers: centered footer, `Fira Sans`, 9pt

### Cover Page

- Dark background (`#0d1117`)
- Logo (`assets/logo.jpg`) centered, 60% page width
- "Enhanced Liberty" in gold, 28pt, bold
- "GTA IV Modlist — v1.0.8.0" in white, 14pt
- "Wave 0: Fresh Off the Boat / Wave 1: City of Dreams" in light gray, 10pt
- Page numbers on all subsequent pages

## Mod Entry Format

Each mod entry in `.md` files:

```markdown
### [Mod Name](https://url-to-mod-page)

| Field             | Value                          |
|-------------------|--------------------------------|
| **Version**       | x.y.z                          |
| **Dependencies**  | Mod A, Mod B                   |
| **System Impact** | Bullet damage, police response |

Description (2-3 lines taken from mod page).

Installation notes specific to 1.0.8.0.
```

- **No "Wave" field** — wave is implied by which file the mod is listed in
- **Categorized within each file** — mods grouped under subheadings (e.g., `=== UI Improvements`, `=== Bug Fixes`, `=== Graphics`, `=== Content`)
- PDF rendering: clickable name (hyperlink), dependency list, system-impact badge (orange tag)

## Wave 0 Mod Categories (placeholders for `02-wave-0-mods.md`)

- **UI Improvements** — map enhancements, HUD tweaks, menu fixes
- **Bug Fixes** — stability patches, quest fixes, crash fixes
- **Audio** — radio station fixes, sound improvements (if compatible)
- **Misc/Quality of Life** — load time improvements, convenience tweaks

No game-mechanic-changing mods. No graphics overhauls. No content additions.

## Wave 1 Mod Categories (placeholders for `04-wave-1-mods.md`)

- **Graphics** — ENB, texture packs, draw distance, lighting, weather
- **Content** — new vehicles, weapons, missions, map additions
- **Mechanics** — driving physics, damage models, police AI, economy
- **Audio** — radio station packs, sound overhauls

## FusionFix Configuration (`06-fusionfix-config.md`)

Organized by category:

- **Graphics** — resolution, framerate, shadows, reflections, AO
- **Controls** — mouse fix, controller mapping, input lag
- **UI** — map scale, radar, HUD elements
- **Memory/Stability** — patch memory, streaming, VRAM
- **Misc** — skip intro, radio, train tracks

Each setting: name, default value, recommended value (if changed), explanation.

**Cross-referenced from Wave 1 guide** — `05-wave-1-guide.md` will link to specific settings in `06-fusionfix-config.md` by section heading. Example: "Enable `DisableClipTeleport` (see FusionFix Config → Stability) to prevent streaming crashes."

Wave 0 uses FusionFix defaults. Wave 1 enables specific tweaks to support its expanded mod setup.

## Mod Installation Order (`01-installation.md`)

Must document the correct installation sequence to avoid conflicts and crashes:

1. Clean GTA IV 1.0.8.0 installation (or downgrade procedure)
2. FusionFix (version-pinned) — always first
3. Script hook / mod loader dependencies
4. Graphics mods (applied last to avoid overwrites)
5. Content mods (vehicles, weapons, map)
6. Mechanics mods (physics, AI, damage)
7. Audio mods
8. Configuration / ini edits
