# Beyond the Surface — AI Agent Instructions

## Project Purpose

A 3-wave Terraria modlist and game guide. Each wave is a fresh playthrough with increasing difficulty. Output is a 100+ page PDF generated via Typst 0.15.

## Tech Stack

- **PDF Engine:** Typst 0.15
- **Markdown Conversion:** pandoc (converts guide/*.md to template/generated/*.typ)
- **Build Script:** PowerShell 7+ (build.ps1, invoked by build.bat)
- **Mod Data:** YAML files in data/ are converted to formatted markdown by build.ps1

## File Conventions

- **Source content:** Markdown files in `guide/` (human-edited)
- **Mod data:** YAML in `data/` (user-provided, converted to markdown by build.ps1)
- **Typst template:** `.typ` files in `template/` (generated by pandoc from guide/*.md)
- **Generated output:** `output/beyond-the-surface.pdf`
- **Excluded from PDF:** `conflicts.md`, `mod-ideas.md` (developer reference only)

## Mod Content Policy

All mod content (modlist.md, conflicts.md, mod-ideas.md) is user-managed. The build system generates these files from `data/*.yaml`. Do not add or remove mods without user approval.

## Build Process

```powershell
.\build.bat
```

This runs build.ps1 which:
1. Checks for typst and pandoc on PATH
2. Converts data/*.yaml to guide/*/modlist.md (and conflicts.md, mod-ideas.md)
3. Converts guide/**/*.md to template/generated/*.typ via pandoc
4. Runs `typst compile template/main.typ output/beyond-the-surface.pdf`

## Guide Content Tone

- Wave 0: Instructional, assumes zero knowledge, occasionally humorous
- Wave 1: Strategy-focused, assumes one vanilla playthrough
- Wave 2: Expert-level, assumes Moon Lord defeated, includes player challenges
