# Known Conflicts

Known incompatibilities between mods.

- Mega Scoreboard Pack 2026 v2 × UML v3: UML ships exclusive scoreboards; the pack overrides them. Use one or the other.
- Gondowan Final EDIT File × UML / private patches: Gondowan targets the stock v2.20 database; installing over UML corrupts custom DB work. Also overwrites any Edit Mode customs — back up EDIT00000000 first.
- Touchline (ML companion) × BudgetSetter.lua: the Touchline installer auto-disables BudgetSetter; the two must not run together.
- Menu themes (e.g. New Menu PES Street 27): only one menu UI mod active at a time.
